# Aeries Playground 3.1.2 prerelease

Open **Grade testing lab → Personal comments** to write a note on a posted assignment. While testing scores, the **Comment** button on the assignment opens the same editor. Saved notes appear beside any teacher feedback in the gradebook table and on the assignment card. To revise a note, edit it and select **Save comment**. To clear it, select **Remove comment**.

The userscript manager stores notes by profile, school year, course, and assignment number. Notes are local to the script’s storage and may be included in the manager’s sync or backups. Grade calculations continue to use posted grades.

To install this prerelease, open `aeries-playground.user.js` under **Assets** and replace your existing copy in your userscript manager. Keep one copy enabled and reload Aeries. Updates are manual.

Fictional gradebook fixtures cover both display modes, saving and removing notes, and changes from another tab. Live Aeries and Tampermonkey behavior remain unverified.
