## What the proposal changes

This is a complete editorial replacement with a new identity, not a claim that the existing license can be silently rewritten. It separates definitions, permissions, private use, review, distribution, source delivery, boundaries, earlier grants, breach, and warranty terms.

| Area | Proposed clarification relative to Version 1.0 |
| --- | --- |
| Scope and ownership | Defines covered work and distribution, preserves separate ownership, and makes the limits of each licensor's authority explicit. A contributor does not assign copyright merely by contributing. |
| Private operation | States explicitly that network interaction without receipt of a copy is not distribution; supplying an actual copy remains distribution. The existing absence of a network-service source-publication duty is preserved. |
| Review | Keeps full-source AI, scanner, human, and paid-service permissions, including working changes, returned patches, processors, records, and published findings. Clarifies that private review does not itself create confidentiality duties or remove the recipient's license rights. |
| Distribution | Preserves notices, change descriptions and dates, the same-license condition, and source access for recipients. An authorized official release or endorsement is distinguished from an unauthorized claim. |
| Source delivery | Makes matching-version source and availability when supplying the copy explicit. Keeps the existing maintenance period while that version is distributed; adds no fixed archival period or public-release requirement. |
| Revision identity | Names Version 1.1 in the same-license condition. Requires actual authority to adopt changed terms and makes clear that neither future revisions nor this proposal automatically apply. Earlier Version 1.0 and valid MIT grants remain available for the material they cover. |
| Breach and liability | Preserves the written-notice and 30-day correction structure, downstream rights, and the warranty/liability limits subject to law. Makes timely correction's effect express. |

The proposal retains commercial use and distribution for any person, field, and technology. It adds no patent clause, copyright assignment, royalty, indemnity, choice of court, field-of-use restriction, automatic later-version option, or claim of OSI approval. Compatibility with another license is not established merely by similar wording.
